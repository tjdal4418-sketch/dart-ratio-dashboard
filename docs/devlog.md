### 내린 결정과 이유
- **역할별로 파일 분리**: `dart_client`(API 호출) → `parser`(정리) → `calculations`(계산) → `app`(화면).
  면접에서 데이터 흐름을 파일 단위로 설명할 수 있고, 계산 로직은 API 없이 테스트할 수 있습니다.
- **분기·반기 비율은 연환산**: 3분기 누적 손익을 그대로 쓰면 ROE 등이 연간 수치보다 작게 나와
  사업보고서 기준 비율과 비교할 수 없습니다. 그래서 누적 × (12 / 누적 개월 수)로 환산하고 화면에 표시합니다.
- **분기 보고서의 기초 잔액은 전년도 말 잔액**: 분기 재무상태표의 전기(frmtrm) 값이 전년도 말이고,
  이것이 회계연도 기준 기초 잔액입니다.
- **비교 기업은 사용자가 직접 선택**: 업종 자동 추천은 기업마다 API 호출이 늘어나 향후 계획으로 미뤘습니다.

## 1단계: 환경 세팅 · git (2026-10-18)

### 한 일
- `git init`을 하고 **가장 먼저 `.gitignore`를 만들어** `.env`(API 키), 캐시 폴더, `__pycache__`, corpCode 파일, `.venv`를 제외했습니다.
- 가상환경(`.venv`)을 만들고 `requirements.txt`의 라이브러리를 설치했습니다.
- 폴더 뼈대(`src/`, `tests/`, `scripts/`, `docs/`), `.env.example`, README 초안을 만들었습니다.

### 내린 결정과 이유
- **라이브러리 버전 고정(`==`)**: 나중에 Streamlit Cloud에 배포할 때도 내 PC와 같은 버전이 설치되도록 했습니다.
- **`.env.example` 커밋**: 실제 키가 든 `.env`는 올리지 않고, 어떤 변수가 필요한지만 알려주는 예시 파일을 올립니다.

### 겪은 문제와 해결
- **Python이 설치되어 있지 않았음** → python.org에서 설치했습니다.
  - Windows의 "앱 실행 별칭"이 `python` 명령을 Microsoft Store로 연결하고 있어서, 설치 안내에 이 기능을 끄는 방법을 넣었습니다.
- **설치된 버전이 3.15(막 출시된 최신판)였음**
  - 새 버전이 나온 직후에는 pandas 등의 설치 파일(wheel)이 아직 없는 경우가 있어서, 설치 전에 `pip install --dry-run --only-binary :all:`로 확인했습니다.
  - 모든 라이브러리가 3.15를 지원해서 그대로 사용하기로 했습니다.
  - 배포 시 Streamlit Cloud에서 3.15를 고를 수 없으면 3.13을 선택할 예정입니다. 코드는 특정 버전 기능에 의존하지 않게 작성합니다.
